# Домашнее задание: Вычисление функций

Программа вычисляет значения двух функций \(f_a(x)\) и \(f_b(x)\), а также их произведение, квадрат разности и удвоенную сумму.

## Математические формулы

### Функция \(f_a(x)\) 

$$
f_a(x) = \begin{cases} 
x^2 - 3x + 9, & \text{если } x \le 3 \\
\dfrac{1}{x^3 + 3}, & \text{если } x > 3 
\end{cases}
$$
### Функция \(f_b(x)\)

$$
f_b(x) = x \cdot e^{\sin(x^2)}
$$

1. Алгоритм

1. Начало
2. Установить локаль для корректного вывода кириллицы (setlocale).
3. Запросить у пользователя и ввести значение x.
4. Вычислить f_a(x):
   · Если x \le 3, то f_a = x^2 - 3x + 9.
   · Иначе f_a = 1 / (x^3 + 3).
5. Вычислить f_b(x): f_b = x \cdot e^{\sin(x^2)}.
6. Вычислить дополнительные значения:
   · Произведение: P = f_a \cdot f_b
   · Квадрат разности: D = (f_a - f_b)^2
   · Удвоенная сумма: S = (f_a + f_b) \cdot 2
7. Вывести на экран значения x, f_a(x), f_b(x), а также вычисленные P, D, S.
